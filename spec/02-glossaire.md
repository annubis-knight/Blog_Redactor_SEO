# Glossaire

| Terme | Définition |
|---|---|
| **Silo** | Un grand rayon du blog, qui regroupe plusieurs cocons. |
| **Cocon** | Une famille d'articles liés autour d'un même thème, organisée en arbre. |
| **Pilier** | L'article de tête d'un cocon : le guide complet. Un seul par cocon, créé en premier. |
| **Intermédiaire** | Un article né d'une section du pilier, qui la développe en profondeur. |
| **Spécialisé** | Un article né d'une section d'un intermédiaire, qui répond à une question précise. |
| **Niveau (d'article)** | Pilier, intermédiaire ou spécialisé. Il fixe la longueur visée, le nombre de chapitres et de questions de FAQ. |
| **Parent, section libre** | Le parent d'un article est l'article du niveau au-dessus dont il naît. Une section libre est un chapitre (H2) du parent qui n'a pas encore d'article. |
| **Parent rédigé** | Un article dont le premier jet est accepté. Seul un parent rédigé peut avoir des enfants. |
| **Carte indicative** | La proposition de plan du cocon, au Cerveau. Elle guide la création des articles ; elle n'en crée aucun. |
| **Stratégie** | Cible, douleur, angle, promesse, appel à l'action (CTA). Celle du cocon est transmise à l'IA à chaque génération qui la concerne. |
| **Douleur** | Le problème du lecteur auquel l'article répond. Elle oriente la pertinence des mots-clés. |
| **Aiguillage** | L'étape de la stratégie d'article qui le situe dans le cocon : niveau suggéré, parent, enfants. |
| **Intention** | Ce que cherche l'internaute : s'informer, comparer, acheter, trouver un site. |
| **SERP** | La page de résultats de Google pour une recherche. |
| **PAA** | « People Also Ask » : les questions associées que Google affiche dans ses résultats. |
| **Capitaine** | Le mot-clé principal d'un article. Un seul, verrouillé au Moteur. |
| **Lieutenants** | Les mots-clés secondaires qui structurent les chapitres de l'article. |
| **Structure** | Le plan de l'article : un titre H1, des chapitres H2, des sous-parties H3. |
| **Lexique** | Le vocabulaire d'expert attendu sur le sujet, tiré des pages concurrentes. |
| **Longue traîne** | Un mot-clé plus long et plus précis, moins cherché mais plus facile à atteindre. |
| **Score Marché (affiché « Score KPI »)** | Le potentiel d'un mot-clé sur le marché : volume de recherche, difficulté, coût par clic, questions, intention, suggestions. |
| **Score Pertinence** | L'accord d'un mot-clé avec la douleur de l'article. Calculé et affiché à part du Score Marché. |
| **Verdict** | L'étiquette d'un candidat capitaine : GO, ORANGE, NO-GO, ou GRAY (gris, « Données insuffisantes ») quand les données manquent. |
| **Cannibalisation** | Deux articles du même site qui visent le même mot-clé et se font concurrence. |
| **Étape (ou check)** | Une case cochée quand une étape est franchie : six au Moteur, une à la Rédaction (« Premier jet accepté »). |
| **Verrouiller** | Figer une décision (capitaine, lieutenants, structure, lexique). |
| **Porte (de qualité)** | Un contrôle placé à un passage sensible : verrouiller le capitaine, valider les lieutenants, la structure, le lexique, accepter le premier jet, publier. |
| **Alarme graduée** | La fenêtre ouverte par une porte qui refuse. Trois niveaux : 🟠 « Attention » (« J’ai lu » suffit), 🔴 « Risque » (catégorie + raison d'au moins 20 caractères), ⛔ « À corriger » (« il ne se déroge pas »). |
| **Dérogation** | La décision écrite de passer outre une alerte 🟠 ou 🔴. Elle vaut pour ce point et ses données : elle tombe dès que ce point change, pas quand on retouche autre chose. |
| **Premier jet** | La première version de l'article, écrite en un seul appel, sans recherche web. |
| **À sourcer** | Le marqueur posé sur un chiffre sans source, que la passe « sources » doit confirmer ou faire disparaître. |
| **Passe d'enrichissement** | Une amélioration proposée chapitre par chapitre après le premier jet (sources, exemples, tableaux, images, FAQ, résumés). |
| **Méta** | Le titre et la description qui s'affichent dans les résultats de Google. |
| **Maillage interne** | Les liens d'un article vers les autres articles du site. |
| **Statut** | « À rédiger », « Brouillon » (posé par le robot), « Publié ». |
| **Mode simulé / mode réel** | Sources factices et gratuites, ou vraies et facturées (voir [Mode simulé et mode réel](01-produit.md)). |
| **Plafond de dépense** | Le budget maximal de données Google payantes sur une fenêtre de temps glissante. |
| **Pile d'activité** | Le panneau flottant « Coûts API », en bas à gauche de chaque écran : coûts d'IA, opérations en base, erreurs connues et dépense DataForSEO de la session. |
| **Pause (du robot)** | Un arrêt du mode automatique qui attend la validation de l'utilisateur. À ne pas confondre avec une porte de qualité. |
